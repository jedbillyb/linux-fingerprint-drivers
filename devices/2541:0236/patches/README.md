# Patches for Chipsailing CS9711 (2541:0236, 2541:9711)

No patch files are mirrored here. The driver is maintained as a full libfprint
fork (see `../CREDITS`); build that fork or install the AUR package.

The AUR package `libfprint-cs9711-rebase-git` carries the driver as a patch series
against libfprint git master, which is the cleanest reference if you want to
rebase the driver yourself.
